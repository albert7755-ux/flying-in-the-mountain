# 峽谷鬼影計時賽

第一人稱戰機座艙視角，貼著河谷低空穿越寫實的山谷。起飛前會先看一張這檔債的**任務簡報**（條件卡），沿途有 3 道**考題**：每題前方並排兩道門，各寫一個答案，轉向飛進正確的那一道。**藍色門**可以瞬間加速。
畫面上半透明的**鬼影戰機**會重播排行榜第一名（或你自己最好那一次）的飛行路線，讓你一路追著它飛。

任何人打開網址就能玩，輸入名字就能上共同排行榜，**不需要註冊任何帳號**。

**排名規則**：成績＝飛行時間＋每答錯一題（或兩道門都沒飛進去）加 5 秒，秒數越少排越前面。同一個名字只保留最好的一次。

---

## 檔案有哪些

| 檔案 | 用途 | 你需不需要改 |
|---|---|---|
| `app.py` | Streamlit 外殼，負責把遊戲顯示出來 | 幾乎不用 |
| `game.html` | 遊戲本體（峽谷、戰機、閘門、鬼影、排行榜） | 換債券時改這支 |
| `schema.sql` | 在 Supabase 建資料表的指令 | 只跑一次 |
| `requirements.txt` | 要安裝的套件 | 不用 |

## 部署步驟（約 10 分鐘）

跟「債速配」、「富邦大樓飛行」用**同一個 Supabase 專案**就好，不用再開新的。

### 第一段：在原本的 Supabase 專案多建一張表

1. 到 [supabase.com](https://supabase.com)，打開原本那個專案
2. 點左邊選單的 **SQL Editor** → **New query**
3. 把 `schema.sql` **整份貼進去**，按右下角 **Run**
4. 看到綠色的 `Success` 就成功了。它會新建一張 `canyon_scores`，不會動到原本的表

### 第二段：把程式放上 GitHub

1. 在 GitHub 開一個新的 repository，例如 `canyon-game`
2. 按 **Add file → Upload files**，把這 5 個檔案拖進去，再按 **Commit changes**

### 第三段：部署到 Streamlit Cloud，並接上資料庫

1. 到 [share.streamlit.io](https://share.streamlit.io) → **Create app**
2. 選剛剛那個 repository，Main file path 填 `app.py`，按 **Deploy**
3. 部署完成後，點右下角 **⋮ → Settings → Secrets**
4. 貼上這兩行。**跟富邦大樓飛行那個 App 的 Secrets 一模一樣**，直接複製過來就好：

```toml
SUPABASE_URL = "https://你的專案代號.supabase.co"
SUPABASE_ANON_KEY = "eyJhbGciOi...（很長一串）"
```

5. 按 **Save**，App 會自己重新啟動
6. 填名字飛一輪，排行榜出現你的名字就成功了。再飛第二輪時，選「排行榜第一名」就會看到你自己的鬼影

## 操控方式

**電腦**：←→ 壓坡度轉彎、↑↓ 爬升/下降、Shift 加速、空白鍵減速、R 回到航線。

**手機**：開始畫面可以選兩種操控方式：
- **虛擬搖桿**：左下角搖桿往左右拖是轉彎，往上推是爬升；右邊有加速、減速、回航線三個按鈕
- **傾斜手機**：像握方向盤一樣左右傾斜手機來轉彎，把手機上緣往自己拉是爬升。建議把手機橫著拿。倒數的時候，手機當下的角度會被當成「水平」

選了傾斜手機，iPhone 會跳出「允許動作與方向」，要按**允許**。如果手機不支援或沒有允許，遊戲會自動切回虛擬搖桿。

覺得上下方向相反的話，把開始畫面的「上下反轉」打勾就好。

## 調整操控手感

打開 `game.html` 搜尋 `const ROLL_MAX=`：

```javascript
const ROLL_MAX=.95,TURN=.85,PITCH=.55;
```

- `ROLL_MAX`：機身最多傾斜多少（越小越不會歪）
- `TURN`：轉彎快慢（越小轉得越慢）
- `PITCH`：爬升、下降快慢（越小越不靈敏）

一次只改一點點，例如 0.85 改成 0.75，再飛看看。

## 平常怎麼維護

### 換題目、換債券

用文字編輯器打開 `game.html`，搜尋下面幾個地方：

**① 任務簡報**：起飛前會先跳出這檔債的條件卡，讓大家記住再飛。搜尋 `const BRIEF_TITLE=`

```javascript
const BRIEF_TITLE='Alphabet 4';
const BRIEF=[
  {k:'債券代碼',    v:'WMBB26040004'},
  {k:'Offer Price', v:'94.88'},
  {k:'YTM',         v:'5.51%'},
  {k:'剩餘年期',    v:'9.38 年'}
];
const BRIEF_SECONDS=20;
```

`k` 是欄位名稱、`v` 是數值，可以增減。`BRIEF_SECONDS` 是簡報最多停留幾秒，時間到會自動起飛。簡報時間不算在飛行成績裡。

**② 考題**：搜尋 `const QUIZ=[`

```javascript
const QUIZ=[
  {q:'記憶題：剛剛簡報裡，這檔債的 YTM 是？',  ok:'5.51%', no:'4.51%'},
  {q:'推理題：申購價 94.88，屬於？',            ok:'折價',  no:'溢價'},
  {q:'推理題：市場利率上升，這檔債的價格會？',  ok:'下跌',  no:'上漲'}
];
```

- `q` 是題目，會顯示在畫面上方
- `ok` 是正確答案，`no` 是錯誤答案，各寫在一道門上
- 正確答案在左邊還是右邊，程式會固定安排，你不用管
- 建議「一題考簡報裡的條件、兩題考推理判斷」，玩家才不會覺得在亂猜
- 題目可以增加或刪掉，建議 3～6 題。每一行最後要有逗號，最後一題不用
- 門上的字不要太長，6 個字以內最好讀

**③ 報價註記**：搜尋 `QUOTE_NOTE`，改成新的報價日和債券名稱。開始畫面上方的 `WMBB26040004 · 低空穿越任務` 也記得一起改。

**④ 排行榜代號**：換一檔債就換一個 id，排行榜和鬼影才不會混在一起

```javascript
var BOARD_ID="alphabet4-canyon";   // 改成例如 "msft-bond-03-canyon"
```

### 清空排行榜

到 Supabase → **Table Editor** → `canyon_scores`，勾選要刪的列再刪除。
也可以在 SQL Editor 跑這一行：

```sql
delete from public.canyon_scores where board = 'alphabet4-canyon';
```

排行榜清掉之後，「第一名鬼影」也會跟著重來。

## 常見狀況

**排行榜一直是空的，或顯示「尚未設定連線」**
Secrets 沒設定好。回 Streamlit 的 Settings → Secrets 檢查那兩行，值要用雙引號包起來。

**顯示「找不到資料表 canyon_scores」**
第一段的 `schema.sql` 還沒跑，或是跑到別的專案去了。

**之前跑過舊版 schema.sql，現在成績送不出去**
新版多了「總題數」欄位。把新的 `schema.sql` 整份再跑一次就會自動升級，舊資料不會被刪掉。

**選了「排行榜第一名」卻沒有鬼影**
要有人用名字完成一輪，才會留下鬼影。還沒有人留紀錄的時候，會改追你自己在這台裝置上的最佳紀錄。

**手機很卡**
換一支比較新的手機，或關掉其他 App 再試。這個遊戲的山谷地形和樹林很多，對手機的負擔比較大。

**同事說打不開**
Streamlit Cloud 免費版太久沒人用會進入休眠，第一個打開的人要等大約 30 秒讓它醒來。

## 安全性說明

- 程式裡的 `anon` 金鑰本來就是設計給瀏覽器用的，公開也沒關係
- 資料庫只開放「讀取」和「新增一筆」，**沒有開放修改和刪除**，沒有人能洗掉別人的成績
- 資料表會檢查名字長度、時間是否合理，而且「成績」一定要等於「飛行時間＋漏門罰秒」
- 鬼影資料只有飛行座標，沒有任何客戶資料
- 遊戲頁面附註「僅供內部教育訓練使用，非投資建議」
